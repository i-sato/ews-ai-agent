# Kebijakan Keamanan

## Melaporkan kerentanan

Jangan membuka issue publik. Kirim laporan ke tim pengelola aplikasi di instansi (alamat surel keamanan diisi oleh pemilik repositori) dengan:

- deskripsi dan dampak,
- langkah reproduksi,
- versi/commit yang terdampak.

Laporan dikonfirmasi paling lambat 3 hari kerja. Jangan menyertakan data peserta riil dalam laporan.

## Acuan

Kontrol keamanan dan status implementasinya ada di `docs/security_hardening_ews_ai_agent.md` (OWASP ASVS Level 2, API Security Top 10, LLM Top 10).
