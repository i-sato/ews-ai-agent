# Antarmuka (desain di `docs/design/`)

- Ikuti layar pada `docs/design/`. Menu utama web: Dashboard, Pelatihan, Peserta, Pemantauan Risiko, Indikator PK, Laporan, Pengaturan. Mobile: tab bawah sesuai desain M-*. Jangan menambah menu.
- Web responsif (PWA) dari kode yang sama; tidak ada aplikasi native.
- Bahasa Indonesia, format tanggal Indonesia, WIB. Angka memakai pemisah ribuan titik dan desimal koma (`74.210`, `94,8%`).
- Status risiko: Kritis, Waspada, Normal, Data tidak memadai, Data tidak valid, Tidak dapat dinilai. Status tidak hanya dibedakan dengan warna; selalu ada label teks.
- Tampilan kesegaran data menyebut minimal dua waktu ("Dicek … · isi berubah …").
- Pernyataan kepatuhan (§11.3) tampil di login, formulir tambah pelatihan/impor, panel AI Agent, dan laporan.
- Target sentuh minimal 44px di mobile; kontras teks memenuhi WCAG AA; fokus keyboard terlihat.
- Tanpa `dangerouslySetInnerHTML`. Teks dari sheet dirender sebagai teks.
- Daftar peserta dan matriks peserta × item hanya untuk role berwenang; role lain melihat agregat.
